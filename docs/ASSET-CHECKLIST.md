# Asset checklist

Use assets supplied or explicitly approved by the client. Confirm usage rights and the displayed alt text before copying files into the repository. Keep originals and private source documents outside the project.

| Asset | Crop and minimum size | Suggested filename and location | Before adding |
| --- | --- | --- | --- |
| Crochet product photo | 4:5 portrait; at least 1,600 px on the long edge (for example, 1,280 × 1,600) | `public/images/products/crochet-{slug}-01.jpg` | Show the actual item; provide accurate alt text; add its public path and alt in the product JSON. |
| Peanut product photo | 1:1 square; at least 1,600 × 1,600 px | `public/images/products/peanuts-{slug}-01.jpg` | Do not imply an unconfirmed variety, pack size, ingredient, allergen or certification. |
| Founder portrait | 4:5 portrait; at least 1,600 px on the long edge | `public/images/brand/founder-portrait.jpg` | Obtain permission to publish; use an accurate alt description. |
| Primary logo | Horizontal, editable SVG with transparent background | `public/images/brand/logo.svg` | Remove editor metadata and external references; keep a transparent PNG export as `logo.png` for handover/design use. The page uses the SVG. |
| Social card | 1,200 × 630 px | `public/social-card.png` and source `public/social-card.svg` | The checked-in card is generated by `pnpm generate:social-card`; regenerate after approved brand/font changes. |
| Browser icon and manifest | SVG icon and valid web manifest | `public/favicon.svg`, `public/site.webmanifest` | Update and verify together if replacing the icon. |

Product photos are referenced directly from `public/` by their site-root URL and are not automatically converted by an image CDN. Export web-ready sRGB JPEGs before adding them, at the required crop and dimensions; compress them to a sensible size and remove location/EXIF metadata. The product page and cards set image dimensions and crop crochet to 4:5 and peanuts to square. Gallery content uses the same URLs and alt text.

For additional views use `crochet-{slug}-02.jpg`, `crochet-{slug}-03.jpg`, or the corresponding `peanuts-{slug}-02.jpg` pattern, and add each approved file to that product's `images` array in display order. Use kebab-case `{slug}` identical to the product JSON slug. Do not place receipts, bank details, CAC certificates or other private documents in `public/` or `src/assets/`; the build checks reject private-document filenames and known prohibited third-party references.

Before committing, check crop, focus, contrast, alt text, file size, desktop and mobile presentation, and that no personal location metadata remains. Only the social PNG is generated by the repository; product imagery is not transformed at build time.
